# 民法典 RAG 样本数据说明

## 数据定位

`data/processed/civil_code_articles_50.jsonl` 是用于跑通一期 RAG 的小规模样本，不能作为完整法律知识库。数据直接从用户提供的《民法典》PDF 文字层抽取，共 50 条，每条法条对应一个 chunk。

## 选条范围

- 民事主体与行为能力：第 13、17-20 条
- 民事法律行为及诉讼时效：第 143-157、188 条
- 物权与业主权利：第 209-301 条中的常用条款
- 合同通则及典型合同：第 465-658 条中的常用条款
- 婚姻家庭：第 1042-1087 条中的常用条款
- 侵权责任：第 1165、1179 条

覆盖问题包括未成年人行为效力、合同成立、格式条款、违约金、赠与撤销、夫妻财产和债务、离婚、子女抚养及人身损害赔偿。

## 字段说明

- `chunk_id`：稳定唯一标识，例如 `civil-code-1062`
- `law_name`、`document_number`、`issuing_authority`：法规身份信息
- `promulgation_date`、`effective_date`、`status`：时效信息
- `article_number`、`article_label`、`article_title`：法条定位信息
- `content`：法条原文，不包含条号和释义标题
- `retrieval_text`：供 BM25 和向量模型索引的增强文本
- `source_file`、`source_pages`：本地来源追溯
- `content_sha256`：用于检查内容在更新前后是否变化

## 推荐用法

1. BM25 对 `retrieval_text` 建索引，并对法律名、条号和标题提高权重。
2. 向量检索同样嵌入 `retrieval_text`，返回结果时展示 `content`。
3. 使用 `chunk_id` 对 BM25 和向量结果去重，再用 RRF 融合。
4. 生成答案时把 `law_name`、`article_label`、`content` 一并交给模型。
5. 程序校验答案里的条号必须存在于本轮检索结果中。

## 限制

- 这 50 条是功能验证集，不代表《民法典》的完整覆盖。
- PDF 中的【标题】属于资料整理时附加的条旨，不是法条正文；因此正文与标题分字段存储。
- 当前只收录一部法律，无法覆盖劳动、刑事、行政及诉讼程序问题。
- 对外提供法律答案前，仍需通过权威在线来源复核法规的现行状态，并加入明确免责声明。
