# 心中的灯塔

夜色渐深，我合上书页，窗外的城市灯火次第亮起。每一盏灯的背后，或许都有一个正在赶路的人。望着那些光，我忽然明白：人生漫长的旅途中，我们都需要一座心中的灯塔。

灯塔，是方向。航海的人若无灯塔指引，便容易在茫茫大海中迷失；行路的人若无目标牵引，纵然脚步匆匆，也可能只是在原地打转。小时候，我总以为努力学习是为了考取好成绩；长大些才懂得，真正的方向不是分数，而是成为一个对社会有用的人。当方向清晰了，脚下的每一步便都有了意义。

灯塔，也是信念。生活并非总是一帆风顺，风浪袭来时，有人选择退缩，有人却迎风而行。发明家爱迪生历经上千次失败才点亮世界上第一盏实用的电灯；史铁生在轮椅上写出了震撼人心的文字。他们之所以能穿越黑暗，正是因为心中有一座不灭的灯塔——那是对理想的坚守，是对生命的热爱。

灯塔，更是一种照亮他人的力量。真正强大的光芒，从来不只是为自己而亮。张桂梅老师扎根大山，用一盏灯点亮了千百个女孩的求学之路；无数平凡的医护人员在深夜的病房里守护着陌生人的安康。他们就像海上的灯塔，静静伫立，却给无数赶路的人带去温暖与希望。

也许我们暂时还成不了照亮别人的灯塔，但至少可以先点亮自己：认真上好每一堂课，读好每一本书，做好每一件小事。当自己足够明亮，光自然会照向更远的地方。

夜更深了，窗外的灯依然亮着。我知道，在这座城市里，有千千万万盏这样的灯，它们彼此守望，汇成星河。愿我们每个人心中都有一座灯塔——照亮自己，也温暖他人。
